<h1>Paradigmas de Linguagens de Programação</h1>

Este repositório foi criado para reunir os materiais, atividades e projetos desenvolvidos na disciplina Paradigmas de Linguagens de Programação, pertencente ao curso de graduação.

O objetivo deste repositório é organizar os exercícios práticos, exemplos de código e demais conteúdos relacionados aos diferentes paradigmas de programação estudados ao longo da disciplina, permitindo acompanhar a evolução do aprendizado e servir como referência para consultas futuras.

<h2>Conteúdo</h2>

Ao longo do semestre, este repositório poderá conter:

- Exercícios propostos em aula;
- Implementações utilizando diferentes linguagens de programação;
- Exemplos de aplicação dos principais paradigmas de programação;
- Trabalhos e projetos desenvolvidos durante a disciplina;
- Anotações e materiais de apoio.
  
<h2>Objetivo</h2>

Este repositório tem caráter acadêmico e foi desenvolvido como parte das atividades da disciplina Paradigmas de Linguagens de Programação, com o propósito de consolidar os conceitos estudados e documentar as soluções implementadas durante o curso.
